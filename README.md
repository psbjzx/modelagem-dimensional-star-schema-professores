# Modelagem Dimensional — Star Schema de Professores

Repositório destinado ao desafio de modelagem dimensional da DIO.

## Status

Planejado. A implementação e os arquivos do modelo serão
adicionados posteriormente.

## Objetivo

Construir um esquema em estrela a partir do modelo relacional
fornecido, com foco na análise de professores, cursos ministrados
e departamentos.

O escopo não inclui a análise de dados dos alunos.

## Etapas previstas

- [ ] Analisar o diagrama relacional disponibilizado.
- [ ] Definir a granularidade da tabela fato.
- [ ] Criar a tabela fato do contexto analisado.
- [ ] Definir as dimensões e seus atributos.
- [ ] Adicionar uma dimensão de datas.
- [ ] Documentar as datas assumidas para o exercício.
- [ ] Definir as chaves e os relacionamentos.
- [ ] Criar e adicionar o diagrama Star Schema.
- [ ] Documentar as decisões de modelagem.

## Entregáveis previstos

- Diagrama dimensional.
- Descrição das tabelas fato e dimensão.
- Documentação da granularidade e dos relacionamentos.
- Arquivos utilizados na construção do modelo.
